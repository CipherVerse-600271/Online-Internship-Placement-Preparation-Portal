# Accessibility review checklist

Review the portal at desktop and mobile widths before presenting it.

- [ ] Keyboard-only use reaches every action in logical order, with visible focus and no keyboard trap.
- [ ] Screen-reader review confirms the page title, heading order, control names, form errors, and status announcements.
- [ ] Text and controls meet WCAG 2.1 AA contrast requirements.
- [ ] At 200% zoom and a 320 CSS-pixel viewport width, content remains usable without two-dimensional scrolling except where the content inherently requires it.
- [ ] An automated axe (or equivalent) WCAG 2.1 AA scan has no unresolved critical or serious findings.
- [ ] Keep desktop and mobile screenshots and the audit notes with the review materials.

Record the tested commit, browser/device, viewport dimensions, tool/version, date, findings, and any follow-up work.
