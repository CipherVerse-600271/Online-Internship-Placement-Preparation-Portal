# Project Documentation

This folder contains the main submission documents and supporting test evidence for the Online Internship & Placement Preparation Portal.

## Main project documents
- `SRS_Online_Internship_Placement_Portal_Team12.pdf` — Software Requirements Specification
- `SAD_Online_Internship_Placement_Portal_Team12.pdf` — Software Architecture Document
- `Test_Plan_Online_Internship_Placement_Portal_Team12.pdf` — Software Test Plan

## Testing and validation reports
- `UNIT_TEST_AND_CODE_COVERAGE_REPORT.md` — backend unit-test results and statement, branch, function, and line coverage.
- `SYSTEM_VALIDATION_REPORT.md` — browser E2E, frontend, accessibility, and pending deployment-level validation evidence.

The reports distinguish checks that passed from activities that still require execution. See `docs/quality/` and `tests/load/` for supporting checklists and test scripts.
